# NFT Monitor

Мониторинг цен на NFT коллекции с OpenSea API. Приложение отслеживает изменения цен, отправляет алерты при значительных изменениях и ежедневные отчеты.

## Функции

### getFloorPrices(collections)

Получает текущие floor цены для списка коллекций NFT с OpenSea.

- **Параметры**: массив строк с slug коллекций (не более 25)
- **Возвращает**: объект с floor ценами для каждой коллекции
- **Использует**: X-API-KEY заголовок для аутентификации

### updatePrices(newPrices)

Обновляет историю цен и рассчитывает изменения.

- **Параметры**: объект с новыми ценами
- **Возвращает**: объект с изменениями за 4 часа и за день
- **Функционал**: сохраняет историю за последние 24 часа

### updatePricesJob()

Основная функция обновления цен, запускаемая по расписанию.

- **Функционал**: получает цены, обновляет данные, отправляет алерты при изменениях >10%

### sendAlertReport(significantChanges)

Отправляет email алерты при значительных изменениях цен (>10% за 4 часа).

### sendDailyReport(changes)

Отправляет ежедневный отчет по изменениям цен.

## Настройка

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Скопируйте файл окружения:

   ```bash
   cp .env.example .env
   ```

3. Заполните переменные в `.env`:
   - `EMAIL_SERVICE`: сервис email (например, yandex)
   - `EMAIL_USER`: ваш email
   - `EMAIL_PASS`: пароль приложения
   - `EMAIL_RECIPIENT`: email получателя
   - `OPENSEA_API_KEY`: ваш API ключ OpenSea

## Получение API ключа OpenSea

1. Перейдите на [OpenSea Developer Portal](https://docs.opensea.io/reference/api-keys).
2. Зарегистрируйтесь или войдите в аккаунт.
3. Создайте новый API ключ в разделе API Keys.
4. Скопируйте ключ и добавьте его в переменную `OPENSEA_API_KEY` в файле `.env`.

## Настройка Yandex SMTP

Для отправки email через Yandex SMTP необходимо выполнить следующие шаги:

### 1. Включение IMAP/SMTP в настройках аккаунта Yandex

1. Войдите в ваш аккаунт Yandex на сайте [mail.yandex.ru](https://mail.yandex.ru).
2. Перейдите в **Настройки** (шестеренка в правом верхнем углу) → **Все настройки**.
3. В разделе **Почтовые программы** найдите **IMAP/SMTP** и включите эту функцию.
4. Сохраните изменения.

### 2. Создание пароля приложения

Yandex требует использования специального пароля приложения вместо основного пароля для SMTP аутентификации:

1. Перейдите в настройки безопасности аккаунта Yandex: [passport.yandex.ru/profile](https://passport.yandex.ru/profile).
2. В разделе **Пароли приложений** нажмите **Создать пароль приложения**.
3. Выберите тип приложения **Почта** (или другое подходящее название).
4. Скопируйте сгенерированный пароль.
5. Используйте этот пароль в переменной `EMAIL_PASS` в файле `.env`.

**Важно:** Не используйте основной пароль аккаунта Yandex - это приведет к ошибке "This user does not have access rights to this service".

### 3. Настройка переменных окружения

Убедитесь, что в файле `.env` установлены следующие переменные:

- `EMAIL_USER`: ваш полный email адрес Yandex (например, yourname@yandex.ru)
- `EMAIL_PASS`: пароль приложения, созданный на предыдущем шаге
- `EMAIL_RECIPIENT`: email адрес получателя уведомлений

## Запуск

Запустите приложение:

```bash
node index.js
```

Приложение будет автоматически запускать обновление цен каждые 4 часа и отправлять ежедневный отчет в 9:00 утра.
